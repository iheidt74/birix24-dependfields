⚙ Abhängige Felder

Konfigurieren Sie kaskadierende Feld-Abhängigkeiten für Ihre CRM-Karten

Wählen Sie das Feld, von dem die Abhängigkeitskette ausgeht. Nur Auswahllisten-Felder sind als Startfeld geeignet.

Legen Sie fest, welche Felder bei welchem Wert des Startfelds angezeigt werden sollen.

Anleitung: Abhängige Felder einrichten

Mit dieser App können Sie kaskadierende Feld-Abhängigkeiten in Ihren CRM-Karten erstellen. Wenn ein Benutzer einen bestimmten Wert in einem Feld auswählt, werden automatisch weitere relevante Felder angezeigt.

Schritt 1: Benutzerdefinierte Felder vorbereiten

Bevor Sie Abhängigkeiten konfigurieren, müssen die benötigten Felder bereits in Bitrix24 existieren.

1.1
CRM-Karte öffnen

Gehen Sie zu CRM → Deals (oder Leads/Kontakte/Unternehmen) und öffnen Sie eine beliebige Karte.

1.2
Felder erstellen

Klicken Sie unten auf "Feld erstellen" und legen Sie alle Felder an, die Sie in Ihrer Abhängigkeitskette verwenden möchten.

Wichtig: Das Startfeld (Elternfeld) muss vom Typ "Liste" (Auswahlliste) sein, damit Abhängigkeiten basierend auf den Listenwerten definiert werden können.
1.3
Listenwerte definieren

Füllen Sie die Auswahllisten mit den gewünschten Werten. Beispiel:

Feld: "Welches Parkett hat Kunde?"
Werte: Landhausdielen, Massivholzdielen, Fertigparkett, Mosaikparkett

Schritt 2: Widget-Feld zur CRM-Karte hinzufügen

2.1
Neues Feld vom Typ "Abhängige Felder" erstellen

In der CRM-Karte auf "Feld erstellen" klicken und den Typ "Abhängige Felder" auswählen.

Geben Sie dem Feld einen Namen, z.B. "Parkett-Konfiguration".

Dieses Feld ist das Widget, in dem die abhängigen Felder angezeigt werden. Es ersetzt nicht die eigentlichen Felder, sondern steuert deren kaskadierende Anzeige.
2.2
Feld zur Kartenansicht hinzufügen

Stellen Sie sicher, dass das neue Widget-Feld in der Kartenansicht sichtbar ist. Sie können es per Drag & Drop in den gewünschten Bereich ziehen.

Schritt 3: Abhängigkeiten konfigurieren

3.1
Entity-Typ wählen

Wechseln Sie oben auf dieser Seite zum gewünschten Tab (Deals, Leads, Kontakte, Unternehmen).

3.2
Neue Konfiguration erstellen

Klicken Sie auf "+ Neue Konfiguration" und vergeben Sie einen aussagekräftigen Namen.

3.3
Startfeld (Elternfeld) wählen

Wählen Sie im Dropdown das Feld, von dem die Abhängigkeitskette ausgehen soll. Es werden nur Auswahllisten-Felder angezeigt.

Beispiel: "Welches Parkett hat Kunde? [UF_CRM_...]"
3.4
Abhängigkeitsregeln definieren

Für jeden Wert des Startfelds können Sie festlegen:

  • Anzuzeigende Felder: Welche Felder sollen erscheinen, wenn dieser Wert ausgewählt wird? Klicken Sie auf "+ Feld hinzufügen" und wählen Sie die gewünschten Felder aus.
  • Pflichtfelder: Aktivieren Sie die Checkbox bei Feldern, die der Benutzer zwingend ausfüllen muss.
Beispiel:
Wenn "Welches Parkett?" = "Massivholzdielen":
→ Zeige Feld "Welche Massivholzdielen hat Kunde?" (Pflicht)
→ Zeige Feld "Holzart" (optional)
3.5
Verschachtelte Abhängigkeiten (optional)

Wenn ein angezeigtes Feld ebenfalls eine Auswahlliste ist, erscheint automatisch der Bereich "Verschachtelte Abhängigkeiten". Dort können Sie weitere Unterabhängigkeiten definieren – beliebig tief.

Beispiel (3 Ebenen):
Parkett = "Massivholzdielen"
  → Massivholzdielen = "Eiche"
    → Zeige: "Oberflächenbehandlung", "Breite", "Länge"
3.6
Speichern

Klicken Sie oben rechts auf "Speichern", um die Konfiguration zu sichern.

Tipp: Sie können mehrere Konfigurationen pro Entity-Typ erstellen, z.B. eine für "Parkett-Typ" und eine andere für "Dienstleistungsart".

Schritt 4: Testen

4.1
CRM-Karte öffnen

Öffnen Sie einen Deal (oder Lead/Kontakt/Unternehmen) und suchen Sie das Widget-Feld "Abhängige Felder" in der Karte.

4.2
Startfeld ausfüllen

Im Widget wird das Startfeld angezeigt. Wählen Sie einen Wert aus – die abhängigen Felder erscheinen automatisch darunter.

4.3
Werte eingeben

Füllen Sie die abhängigen Felder aus. Alle Werte werden automatisch in die nativen Bitrix24-Felder geschrieben und stehen für Filter, Berichte und Dokumentenvorlagen zur Verfügung.

Häufige Fragen

Warum sehe ich mein Feld nicht in der Feld-Auswahl?
Das Feld muss bereits als benutzerdefiniertes Feld in Bitrix24 angelegt sein, bevor es hier konfiguriert werden kann. Erstellen Sie es zuerst in der CRM-Karte.
Welche Feldtypen kann ich als Startfeld verwenden?
Nur Felder vom Typ Liste (Auswahlliste), Ja/Nein oder CRM-Status können als Startfeld genutzt werden, da die Abhängigkeiten auf konkreten Auswahlwerten basieren.
Welche Feldtypen kann ich als abhängiges (Kind-)Feld verwenden?
Alle Feldtypen werden unterstützt: Text, Zahl, Datum, Auswahlliste, Ja/Nein, Geld, URL usw.
Wie viele Verschachtelungsebenen sind möglich?
Es gibt keine Begrenzung. Sie können beliebig tiefe Abhängigkeitsketten erstellen, solange die Zwischenfelder Auswahllisten sind.
Werden die Daten in den nativen Bitrix24-Feldern gespeichert?
Ja. Alle Eingaben im Widget werden direkt in die originalen benutzerdefinierten Felder geschrieben. Sie können die Daten in Filtern, Berichten, Dokumentenvorlagen und Automatisierungsregeln verwenden.
Was passiert, wenn ich den Wert im Startfeld ändere?
Die abhängigen Felder des vorherigen Wertes werden ausgeblendet. Bereits eingegebene Werte in den nativen Feldern bleiben erhalten, werden aber im Widget nicht mehr angezeigt.
Funktioniert die App auch mit Smart Processes?
Ja, Smart Processes werden automatisch erkannt und als zusätzliche Tabs in den Einstellungen angezeigt.
Das Widget zeigt "Keine Konfigurationen vorhanden" – was tun?
Öffnen Sie diese Einstellungsseite, wechseln Sie zum richtigen Entity-Typ-Tab und erstellen Sie mindestens eine Konfiguration mit Startfeld und Regeln. Vergessen Sie nicht, auf "Speichern" zu klicken.
